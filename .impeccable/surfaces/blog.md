# Blog

## What the visitor is doing

Read a post about the work; or, for an author, write and publish one.

## Direction

Read track for the reader; Operate track for the editor. Prose styling lives in `.prose-blog` and draws only from the token set.

## Decisions to preserve

- No amber/cream prose palette: links are the accent, quotes are a severity surface.

## Mode

`Read` — the visitor understands something; structure for comprehension, then make the reading worth staying in.
