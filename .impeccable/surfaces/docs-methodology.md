# Docs Methodology

## What the visitor is doing

Learn how the product works: the pipeline, the model, the data sources, the verification rules.

## Direction

Read track. A documentation index of numbered topic rows (the number is real navigation order, not decoration), then long-form prose with a sticky table of contents on wide screens.

## Decisions to preserve

- Code and identifiers set in the mono face; body set at body-md.

## Mode

`Read` — the visitor understands something; structure for comprehension, then make the reading worth staying in.
