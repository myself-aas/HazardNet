### 4) Key Commands

```bash
npm install                                   # install the npm workspace tree (root)

# Local development (two processes — see frontend/vite.config.ts proxy)
cd frontend && npm install && npm run dev     # Vite dev server, :3000, strictPort
npm run dev:api                               # Express API on :3001 (PORT=3001)
npm run dev                                   # ensure-frontend + backend/server.js (:3000)

# Build / serve
npm run build                                 # build:frontend + scripts/copy-dist.mjs
npm start                                     # backend/server.js serves frontend/dist on :3000

# Tests
npm test                                      # jest --passWithNoTests (root config)
npx jest --ci --testPathIgnorePatterns='/node_modules/' '/e2e/' '/frontend/' '/apps/' '/__mocks__/'
cd frontend && npx jest --ci --config ../jest.config.cjs --rootDir .. --coverageThreshold='{}' frontend/src
npx jest --config apps/mobile/jest.config.cjs # mobile RN suites (must be run from apps/mobile — see TESTING.md)
python -m pytest scripts/tests -q             # pipeline/workflow tests (pytest, PyYAML)
npx playwright test                           # E2E (needs a build + preview server)

# Quality gates
npm run lint                                  # tsc --noEmit
npm run lint:eslint                           # eslint . --max-warnings 685
npm run format                                # prettier --write
npm run check:env  check:claims  check:functions  check:bundle  check:paths  check:design  check:fonts  check:tokens
```

Note: `npm test` runs `jest --passWithNoTests` with **no** coverage gate; CI applies the
coverage thresholds only in the scoped backend job (`jest.config.cjs` → `coverageThreshold`).
