### 4) Key Commands

```bash
npm ci --no-audit --no-fund        # install (CI + Vercel; frozen from package-lock.json)
npm start                          # backend only: node backend/server.js (PORT env; 3001 used in dev per vite proxy)
npm run dev                        # build frontend then start backend
npm run build                      # build frontend (vite) + copy dist to root (scripts/copy-dist.mjs)
npm run lint                       # type-check frontend (tsc --noEmit)
npm run lint:eslint                # ESLint (0-error policy)
npm test                           # jest --passWithNoTests
npm run check:bundle               # bundle budget gate
npm run check:rag-freshness        # RAG freshness gate
cd frontend && npm run dev         # Vite dev server on :3000 (proxies /api,/metrics,/health -> 127.0.0.1:3001)
npx playwright test                # e2e against built app (vite preview :4173) or E2E_BASE_URL
```

## Extended Sections (Optional)

### Dependency-risk notes

- `firebase` npm package is used **both** server-side (Firestore client SDK in `backend/db.js`, against the AI-Studio applet database) and client-side — an unusual dual role that ADR 0001/0002 plan to eliminate.
- `@tensorflow/tfjs-node` (native, ~10× faster inference per `backend/tfjs.js`) is deliberately **not** a dependency; the CPU fallback runs in production unless manually installed (audit P2 deferral).
- npm audit runs in CI with `continue-on-error: true` ("soften until moderate findings are cleared") — `.github/workflows/ci.yml`.
