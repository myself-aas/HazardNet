### 4) Key Commands

```bash
npm ci --legacy-peer-deps            # what CI and the Pages build run; .npmrc also sets the flag
npm run dev                          # ensure frontend build exists, then node backend/server.js
npm run dev:api                      # PORT=3001 node backend/server.js (Vite proxies /api there)
cd frontend && npm run dev           # Vite dev server on :3000 (README)
npm run build                        # build:frontend (+ prerender, markdown) then copy-dist → dist/
npm start                            # node backend/server.js — serves dist/ + API on one port

npm run lint                         # tsc frontend + functions
npm run lint:eslint                  # ESLint, max 600 warnings
npm test                             # jest --passWithNoTests (root config)
npx jest --config apps/mobile/jest.config.cjs --ci --runInBand --forceExit   # mobile (CI form)
npx playwright test                  # E2E; needs a built app on :4173 or E2E_BASE_URL

npm run check:device                 # 14 chained gates (tokens, prose, icons, contrast…, craft)
npm run check:design:source          # design detector over frontend/src
npm run check:design                 # detector over build + source vs baseline
npm run audit:pages                  # document audit of prerendered HTML
npm run protocol:check               # route/surface protocol
npm run check:claims                 # every public numeric claim is registered in CLAIMS.md
```
