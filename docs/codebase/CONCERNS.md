Generated by the `acquire-codebase-knowledge` workflow on **2026-11-17** against commit
`3e7da64` (`main`). Supersedes the 2026-10-25 map (`8a7d0e5`). The concerns are read off files,
committed artifacts, `git log`, and test/lint/gate runs after `npm ci` (2026-11-17, Windows,
Node 24). Rows marked **Decided** or **Fixed** record what changed after the owner answered
the first-pass questions.

**The headline has changed since the last map.** Most of what that map called High is now
closed at HEAD. The lockfile is complete (2,532 entries), all 77 `scripts/` files exist, 19
`serverless/` handlers resolve from every `api/` route table, and the site has a live
same-origin API on Pages Functions. The open risks are now about **operations and product
truth**: how long a published number stays valid, which severities reach the public without a
person, and a flapping live check. Code rot is no longer the main risk.
