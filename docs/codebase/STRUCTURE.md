### 4) Naming and Organization Rules

- **React components:** `PascalCase.tsx`. The exceptions are `components/ui/` primitives in
  kebab-case (`motion-navigation-menu.tsx`, `handoff-beam.tsx`, `globe-3d-lazy.tsx`, `expand-map.tsx`)
  and a few lower-camel helpers (`districtBriefUtils.tsx`, `primitives.tsx`, `a11y.tsx`). Count:
  114 PascalCase vs 10 lowercase basenames.
- **Pages:** `frontend/src/pages/<Name>Page.tsx` or a bare `<Name>.tsx` (`About.tsx`,
  `Dashboard.tsx`). Both styles coexist across 40 files; `pages/dashboard/` holds the blog studio.
- **Hooks:** `use<Name>.ts` (21 files).
- **Backend modules:** lowerCamel `.js`, except two snake_case files
  (`backend/utils/ai_fallback_engine.js`, `backend/utils/gemini_grounding.js`).
- **Scripts:** mixed. Gates use kebab-case (`check-contrast.mjs`); builders and fetchers use
  snake_case (`build_alert_snapshot.mjs`, `fetch_kaggle_advisory.mjs`).
- **Edge routes:** file path = URL (`functions/api/v1/alerts/policy.ts` → `/api/v1/alerts/policy`);
  a list endpoint is `index.ts`, a dynamic segment is `[scope].ts`.
- **Node function routes:** `api/<family>/[param].js`, with the handler at the mirrored path
  under `serverless/`.
- **Tests:** co-located `__tests__/` folders inside `frontend/src/*` and `packages/*`, plus the
  root `__tests__/`. Suffix `.test.{js,ts,tsx,mjs}`; E2E uses `.spec.ts`.
- **Artifacts:** versioned schema strings inside each JSON (`hazardnet-daily-advisories/v1`,
  `hazardnet-alerts/v1`, `hazardnet-site-probe/v1`, `hazardnet-route-register/v1`).
