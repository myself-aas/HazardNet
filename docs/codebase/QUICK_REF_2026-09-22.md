## Key aliases & conventions

- `@/*` → `frontend/src/*`  (both `tsconfig.json` and `vite.config.ts`)
- ESM everywhere; relative imports include `.js`; Jest config is `.cjs`
- Prettier: 120 cols, single quotes, semicolons, 2-space, trailing commas
- District matching: `canonicalKey()` + `DISTRICT_NAME_ALIASES` — keep `data/bangladeshDistricts.ts` / `lib/forecasts.ts` / `scripts/etl/districts.py` in sync
- `IMPORTS` — no enforced sort; follow neighbouring file

## Glossary in one breath

`prediction_date` = Kaggle run date · `target_date` = horizon window end · `severity_score` = 0..1 (model vs physics tracks) · `confidence_kind` = `uncalibrated_model_softmax` until calibration fitted · `dataset_version = ds1.<16hex>` = input content hash · `provenance` = model/tensor/pipeline/run stamp · `coverage` = 128 requested vs produced · `DRAFT→PENDING_REVIEW→PUBLISHED` alert lifecycle.
