### 3) Secrets and Credentials Handling

- **Storage:** GitHub Actions secrets for pipeline jobs (`KAGGLE_*`, `CF_PAGES_DEPLOY_HOOK`,
  `SITE_PROBE_TOKEN`, …); the Cloudflare Pages dashboard for runtime env and bindings; a local
  `.env` (from `.env.example`, 38 empty keys) for self-host. `docs/ENVIRONMENT_SECRETS.md` is
  the human reference.
- **Rotation register:** `data/security/secret-rotation.json`, checked by
  `scripts/check-secret-rotation.mjs` (monthly via `secret-rotation-audit.yml`) and documented in
  `docs/ops/secret-rotation.md`. Measured 2026-11-17: 17 credentials, 0 overdue, 15 with no recorded rotation date.
  (The previous map measured 13 of 15 unrecorded.)
- **Committed public values (by design):** Firebase web config (`firebase-applet-config.json`,
  `firebase-blueprint.json`), Firebase project id, a public VAPID key, the RTDB URL.
- **Scanning gates:** `scripts/check-secrets.sh` (CI `security-audit`),
  `scripts/verify-actions-secrets.sh` + `verify-secrets.yml`, `scripts/check-workflows.mjs`
  (workflows "loadable and secrets-safe"). `AGENTS.md` forbids `secrets.` in any `if:`.
- **Template drift:** `GEMINI_API_KEY` and the SMS/Telegram/Cloudflare keys are read by code
  but missing from `.env.example` (full list in STACK.md §5).
- **Private key on disk (optional):** `backend/server.js` looks for `.bot-private-key.pem` in
  the CWD to sign `/.well-known/http-message-signatures-directory`. That branch cannot run (see
  CONCERNS.md), so a fixed placeholder signature is always served.

### 4) Reliability and Failure Behavior

| Integration | Failure behaviour | Evidence |
| --- | --- | --- |
| Kaggle | No new Ready version → exit 2, "public site unchanged". Unverifiable dataset → job fails and nothing is committed. A new version that changes nothing → **fails** ("refusing a misleading successful update") | `public_daily_advisories.yml:46-61,117-120` |
| Pages deploy hook | Unset → summary note and reliance on Git integration (the commit is `[skip ci]`, so **no build happens**). Set → POST with retries | `public_daily_advisories.yml:130-150` |
| `ASSETS` (edge snapshot read) | Asset error → `console.error` + 503 with a fixed message | `functions/api/v1/forecasts/bulk.ts` |
| Firestore (Node) | Circuit breaker → committed snapshot fallback; re-probes after cooldown | `backend/forecastStore.js:181-224` |
| LLM providers | Per-provider health skip, try/catch per tier, cascade of 5; validated cache entries | `backend/utils/ai_fallback_engine.js:535-560` |
| Open-Meteo | Node: TTL cache. Edge: 502 on upstream shape failure, as observed by the probe on 2026-11-16 | `data/site-health/latest.json` `runtime_paths` |
| SMS/Telegram | Timeouts (`SMS_TIMEOUT_MS`, `TELEGRAM_TIMEOUT_MS`), `SMS_MAX_PER_RUN` (25), `SMS_DRY_RUN` | `backend/alerts/channels/*.js`, `alerts-latest.json` `transports` |
