# SEO Audit — hazardnet.live (2026-11-06)

Method: `seo-audit` skill (marketingskills) framework applied to the static artifacts the
deployment ships (`frontend/public/robots.txt`, `sitemap.xml`, shell `index.html`,
`src/content/site-routes.json`, `SEOHead.tsx`, prerendered `dist/`). No Search Console access
from this sandbox; browser-rendered checks (Rich Results) remain a CI/manual step.

## Executive summary

Overall health: **good technical foundation**. Crawlability, canonicals, structured data,
sitemap and mobile basics are all in place. The actionable findings are on-page length
discipline (over-long titles/descriptions, mostly pre-existing) and the two new `/reports`
routes, fixed in this pass.

### Top priority issues
1. **(Fixed)** `/reports` and `/reports/archive` shipped with a 69-char title and 271-char
   description — both truncated in SERPs. Now 59 chars / 158 chars and 43 / 118.
2. **(Pre-existing, Medium)** 15+ routes carry descriptions >160 chars (e.g. `/status` 325,
   `/last-run` 359, `/live` 228) — Google truncates around 155–160; the cut-off text is lost.
3. **(Pre-existing, Low)** several titles exceed 60 chars (`/live` 79, `/status` 75, `/faq` 69).

### Quick wins
- Keep new routes inside 60/160 limits (enforced for `/reports*` here).
- Trim the longest descriptions (`/status`, `/last-run`, `/live`, `/alerts`) to ≤160.
